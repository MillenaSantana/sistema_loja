Projeto desenvolvido em linguagem **C** como atividade acadêmica da disciplina de Programação.

O objetivo é criar um sistema simples para gerenciar produtos de uma loja, utilizando estruturas (`struct`), funções, arquivos e algoritmos de ordenação.

## ⚙️ Funcionalidades

- Cadastro de produtos com ID automático.
- Listagem dos produtos cadastrados.
- Alteração e exclusão de produtos.
- Validação dos dados e prevenção de nomes duplicados.
- Armazenamento das informações em arquivos `.txt`.
- Ordenação com **Bubble Sort** por nome (A–Z) e preço crescente.
- Exportação dos produtos para CSV.

## 💻 Tecnologias utilizadas

- Linguagem C
- OnlineGDB
- Manipulação de arquivos TXT e CSV
- Algoritmo Bubble Sort

## 📂 Estrutura do projeto

O projeto foi desenvolvido em módulos, posteriormente integrados em um único arquivo para execução.

- `main.c` — Menu principal e integração.
- `loja.h` — Estrutura dos produtos e declarações.
- `cadastro.c` — Cadastro e validação dos produtos.
- `arquivos.c` — Listagem, alteração e exclusão.
- `bubble.c` — Ordenação com Bubble Sort.
